# Data Quality & Governance

## Principles
1. Public-source traceability
2. Minimal sensitive surface
3. Versioned schema changes
4. Explicit evidence confidence

## Validation Checklist
- [ ] Every class has definition + source URL
- [ ] Every relation has domain/range
- [ ] Every metric has formula + period
- [ ] No internal-only document references

## Confidence Tags
- `high`: direct legal/official definition
- `medium`: official report interpretation
- `low`: secondary explanatory material
