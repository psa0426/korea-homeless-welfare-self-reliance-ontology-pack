# Korea Homeless Welfare & Self-Reliance Ontology Pack (Public Sources Only)

This repository provides a public-source ontology starter pack for Korean homeless welfare and self-reliance support.

## Scope
- Public policies, laws, and administrative information only
- No internal documents from facilities/foundations
- No personal/sensitive data (residents, donors, accounting, case records)

## OpenCrab Ingest Target
- branch: `main`
- path: `docs`
- document_limit: `200`
- scan_all_readable_documents: `ON`
